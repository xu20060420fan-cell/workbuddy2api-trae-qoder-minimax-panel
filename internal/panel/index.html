    2. 

  2. 
筛选账号请求，再刷新网页

    在网络面板的筛选框中输入：
    

    package/overview
    

    刷新网页，点击出现的 overview 请求，核对请求地址：
    
https://devcloud.cn-north-4.huaweicloud.com/chat/snap-manager/v1/package/overview

    请跳过 furiondata.myhuaweicloud.com 和 /furiondataserver/fr，它们不是这里需要的码道登录请求。
    

    
筛选后没有请求，或找不到 Cookie？

    确认网页已登录，再打开「活动福利」触发请求。仍没有结果时，清空筛选，选择发往 devcloud.cn-north-4.huaweicloud.com 的 /chat/ 请求，查找请求标头中的 Cookie 一项。
    

    

    3. 

  3. 
只复制 Cookie 这一项的值

    在所选请求中打开 标头 → 请求标头 / Request Headers，找到 Cookie，右键选择 复制值 / Copy value。
    

    正确值示例（仅展示格式）：name=value; name2=value2; name3=value3
    

    请勿复制以 GET / POST 开头的整段请求标头。也不要使用 document.cookie，它读不到 HttpOnly 登录票据。
    

    4. 

  4. 
粘贴 Cookie 值并导入



    可分行粘贴完整的 name=value 项；请勿在单个票据中间手动断行。
